# Reference

## Public API

| item | what it is |
|---|---|
| `Language` output | the assembled definition every engine consumes |
| `data/eval.yaml` | the eval fragment set — scheme per node kind (ADR-0052 v2 kernel) |
| `data/globals.yaml` | the prelude binding surface |
| `data/capabilities.yaml`, `data/caps.yaml` | capability declarations the host gates on |

## Crate

| crate | role |
|---|---|
| `handl-kit-prelude-lang` | language definition as data |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # cargo test
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
